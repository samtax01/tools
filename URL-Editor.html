Shows common and unique query keys across all URLs.

How to use

  1. Paste or type a URL into a card's textarea and press Apply.
  2. Edit query param values inline — the main URL updates automatically.
  3. Add / remove params with the + / trash icons.
  4. Click Share to copy a link encoding all URLs to your clipboard.
  5. Open the page with ?url=...&url=... to preload URLs.
Compact, responsive and editable single-page URL comparator. Built with plain HTML, Tailwind and vanilla JS.
